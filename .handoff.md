## Key Insight
Production Pironman already has the image profile (Gemini 3.1 Flash via OpenRouter). The bug affected **fresh installs** where no IMAGE_* env vars caused empty `{ profiles: [] }` for image service, making `getActiveImageConfig()` return null in the frontend.

## Env Var Conventions
Python-side env vars use flat names: `IMAGE_BINDING`, `IMAGE_MODEL`, `IMAGE_API_KEY`, `IMAGE_HOST`, `IMAGE_API_VERSION` (same pattern as `LLM_*`). TypeScript-side uses provider-prefixed: `IMAGE_OPENROUTER_API_KEY`, etc. Both namespaces are independent.
